This directory is intended for static assets such as logos and videos.

To permanently embed your video in this web application:
1. Place your video file here (e.g. `public/assets/retreat_video.mp4`).
2. When you push to GitHub, the video file will be included in the repository and automatically deployed to your static hosting (GitHub Pages, Vercel, Cloud Run, etc.).
3. If your video file is larger than 50MB-100MB (GitHub file size limit), you can host the video file on Google Drive (direct link) or YouTube (unlisted) and configure the link.
